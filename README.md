This repository documents my **DevOps learning journey** with shell scripting, Python (Flask/Django), Makefile usage, and deployment concepts.  
It includes not only backup/rotation scripts but also advanced topics like functions, variable arguments, loops, conditions, error handling, Flask app builds, and Django deployment.

  - Variable arguments

- Flask app with Makefile

- Git workflow practice (push/pull, branches)
- Day‑wise DevOps exercises

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/DevOpsatomixsiri/Shell-script-DevOps.git
Navigate to a specific day:

bash
cd Shell-script-DevOps/Day05
Run scripts:

bash
./backup.sh <source_dir> <backup_dir>
Build and run Flask app:

bash
make build
make up
Deploy Django app:

bash
python manage.py runserver
